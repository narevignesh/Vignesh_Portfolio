# NARE VIGNESH - AI Engineer Portfolio Website

A personal portfolio website for **Nare Vignesh**, presenting his primary specialization as an **AI Engineer** and secondary specialization as a **Full Stack Developer**.

Designed with a dark developer aesthetic inspired by modern AI product interfaces, featuring electric cyan/indigo accents, glassmorphic cards, responsive code editor, neural particle background, and an interactive full-screen lightbox for verified credentials.

---

## 🚀 Live Demo & Deployment on GitHub Pages

This portfolio is built as a pure, lightweight, modern client-side web application with zero backend dependencies, making it deployable on **GitHub Pages** with no build steps required.

 ### Live on GitHub Pages at:

   **[https://narevignesh.github.io/Vignesh_Portfolio/](https://narevignesh.github.io/Vignesh_Portfolio/)**



## 🛠️ Tech Stack

- **Core Structure:** Semantic HTML5 with SEO meta tags, OpenGraph, and accessible ARIA attributes.
- **Styling:** Custom Vanilla CSS Design System with CSS variables, modern glassmorphism, responsive clamp typography, and micro-animations.
- **Interactivity:** Vanilla JavaScript for:
  - Interactive HTML5 Neural Canvas background with cursor interaction
  - Sticky glassmorphism navbar with scroll spy & active section indicator
  - Mobile hamburger navigation drawer
  - High-resolution Certificate Lightbox Modal with zoom in/out, pan, and escape key listener
  - 3D perspective tilt hover effects on project cards
  - One-click copy email & phone actions with toast feedback
- **Assets:**
  - Real personal photo (`assets/images/profile.jpg`)
  - Authentic AatonovaZ Technologies internship certificate (`assets/images/aatonovaz_certificate.png`)
  - Original certificate PDF document (`assets/docs/aatonovaz_internship_certificate.pdf`)
